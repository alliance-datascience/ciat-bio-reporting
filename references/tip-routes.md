# Output types and TIP routes

Checked in TIP on 2026-11-26. TIP: https://tip.alliance.cgiar.org

| Output type | Formatting? | TIP route | What is submitted |
|---|---|---|---|
| Written document: report, brief, manual, working paper, article, chapter | Yes, if not final | Submit Research Outputs > CGSpace (/CgspaceSubmission/create) | PDF or Word file, up to 20 MB per file |
| Presentation, poster, infographic | No | CGSpace | File or link |
| Video, audio, multimedia | No | CGSpace, metadata only | Link to where it is hosted (YouTube, SlideShare or another repository recommended by the library) |
| Digital tool, platform, website, app, dashboard | No | CGSpace, Digital Tools collection, type Website or Software | Link |
| Software, code, repository (GitHub, Zenodo, Hugging Face) | No | CGSpace, type Software or Source Code | Link, and DOI if any |
| Dataset | No | Submit Research Outputs > Dataverse (/DataverseSubmission) | Data files and data dictionary. The data team publishes in Harvard Dataverse and passes the metadata to CGSpace |
| Innovation | No | Submit Research Outputs > Innovation Dev (/Innovation/star) | Form not mapped yet |
| Training or capacity-sharing event | No | Submit Research Outputs > Capacity Sharing (/CapDev/star) | Form not mapped yet |
| Outcome or outcome impact case | No | Submit Research Outcome > OICR (/OICR/star) | Form not mapped yet |
| Policy change | No | Submit Research Outcome > Policy Change (/Policy/star) | Form not mapped yet |

If the type is unclear, show these options to the user and let them choose.

Rules from the CGSpace FAQ (/cgspaceFAQ):
- Only final or published products. Drafts go to SharePoint and only count as evidence of other results.
- CGSpace is the only approved repository for knowledge products. Datasets and multimedia live in their own repository and are registered in CGSpace with metadata and a link only.
